TfcAnvilHelper.

TfcAnvilHelper — это легковесный мод-помощник для наковальни в TerraFirmaCraft (и сборок вроде TerraFirmaGreg). Он берет на себя всю математику, позволяя сосредоточиться на ковке, а не на подсчете кликов.

Интеллект (BFS): Полностью переписан алгоритм поиска пути. Теперь используется Поиск в ширину (Breadth-First Search). Расчет происходит мгновенно, даже для самых сложных цепочек, без лагов и зависаний игры.

Гарантированная кратчайшая цепочка: Мод всегда находит минимально возможное количество шагов до цели.

Кнопка пропуска (Skip >>): Теперь в уведомлении есть кнопка для ручного переключения шага(Само уведомление и есть кнопка). Полезно для дебага или если наковальня ведет себя странно.

Очистка действий: В меню выбора последних действий добавлена опция - (тире), которая позволяет быстро сбросить слот.

Человеческий интерфейс: Все подсказки выводятся на понятном языке с указанием текущего и следующего шага.

🛠 Установка
Убедитесь, что у вас установлен Minecraft 1.20.1 и Forge версии 47.1.0 или выше.

Скачайте tfcanvilhelper-1.3.jar из раздела Releases.

Поместите файл в папку mods вашего игрового клиента.

📖 Как пользоваться
Откройте интерфейс наковальни (Anvil).

Нажмите на кнопку ⧉ (иконка оверлея) в верхней части экрана.

Целевое число: Введите число, которое показывает стрелка на наковальне.

Действия: Укажите обязательные последние 2 или 3 действия (которые требуются для рецепта). Если действие не нужно, выберите -.

Нажмите Рассчитать.

Внизу появится уведомление с первым действием. После того как вы выполните его на наковальне, мод автоматически покажет следующее.

Кнопка >>: Нажмите, чтобы пропустить текущий шаг.

Кнопка X: Сбросить расчет и закрыть уведомление.
